
Website ini bernama **Ersih Personal Portfolio**, sebuah platform portofolio digital interaktif yang dirancang untuk menampilkan profil dan karya siswa jurusan Rekayasa Perangkat Lunak (RPL). Fungsi utama dari website ini adalah menyajikan informasi diri, keterampilan, pengalaman, serta karya yang telah dibuat dalam bidang pengembangan perangkat lunak secara rapi dan menarik. Dengan adanya website ini, pengguna dapat dengan mudah mengenal profil, kemampuan, dan pengalaman pengembang melalui tampilan yang sederhana dan informatif. Untuk menginstal atau menjalankan website ini, Anda cukup melakukan clone atau mengunduh repository dari GitHub lalu membuka file `index.html` menggunakan browser seperti Google Chrome atau Microsoft Edge. Jika memiliki pertanyaan, saran, atau ingin melakukan kerja sama, Anda dapat menghubungi pengembang melalui email [ersyseburing1@gmail.com](mailto:ersyseburing1@gmail.com).
